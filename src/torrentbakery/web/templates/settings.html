1. Stash needed for Stash scenes

The connection to your Stash instance. It lets TorrentBakery find your scenes (the search on the start page) and read title, studio, performers, tags and the file path. If the scene is linked to StashDB in Stash, the metadata comes from there; the tags always come from Stash.

The way you open Stash in the browser: with http:// and port, without /graphql at the end.

In Stash under Settings → Security → API Key. If Stash has no password, leave this empty.

"Test connection" checks the values in the form, even before saving.

Path mapping (Stash path → path in this container), only for differing paths

Stash reports where each file lives. If this container sees the same share under a different path, this table translates the beginning of the path. A profile bundles what your tracker (or forum) requires for the torrent. You pick a profile when baking; without one the torrent has no announce URL, which no tracker accepts. You can create as many as you like, e.g. one per tracker.

3. Animated cover optional

The cover of the post is a short animation (WebP or GIF) made of 1.5-second clips spread evenly over the whole video (intro and credits skipped). Set the defaults here; on the start page you can change them for each bake.

Stash's preview is the animated preview Stash generates itself (in Stash, the still strip used for scrubbing is called "sprites", the animation "preview"). Its clips and length are decided by Stash, not by TorrentBakery.

Hosts without WebP support (imgbox, imagebam) automatically get a GIF.

0 = automatic: about one clip per 2.5 minutes of video, at least 4, at most 12.

Default 480. Image hosts accept roughly 10 MB at most; if the file is larger, TorrentBakery reduces width, frame rate and quality automatically until it fits.

4. Media folders only for single files

On the start page you can enter a file path such as /media/BF-stshpp/Film/film.mkv instead of a Stash scene. For safety the interface only allows that inside the folders listed here. Stash scenes do not need this setting.

One folder per line, subfolders included. The folder must be mounted and readable in this container.

5. Image hosts optional

Without a host, the cover and the screenshot sheet are only files to download; the post then contains file names and you upload the images yourself. With a host, TorrentBakery uploads the images while baking and puts the links into the post. You choose the host on the start page for each bake.

pixhost.to, pixhost.cc, pixho.st, imgbox, imagebamWork without an account and without settings.
