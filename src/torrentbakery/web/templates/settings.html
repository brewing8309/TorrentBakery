Stash needed for Stash scenes

The connection to your Stash instance. It lets TorrentBakery find your scenes (the search on the start page) and read title, studio, performers, tags and the file path. If the scene is linked to StashDB in Stash, the metadata comes from there; the tags always come from Stash.

The way you open Stash in the browser: with http:// and port, without /graphql at the end.

In Stash under Settings → Security → API Key. If Stash has no password, leave this empty.

"Test connection" checks the values in the form, even before saving.

Animated cover optional

The cover of the post is a short animation (WebP or GIF) made of 1.5-second clips spread evenly over the whole video (intro and credits skipped). Set the defaults here; on the start page you can change them for each bake.

Stash's preview is the animated preview Stash generates itself (in Stash, the still strip used for scrubbing is called "sprites", the animation "preview"). Its clips and length are decided by Stash, not by TorrentBakery.

Hosts without WebP support (imgbox, imagebam) automatically get a GIF.

0 = automatic: about one clip per 2.5 minutes of video, at least 4, at most 12.

Default 480. Image hosts accept roughly 10 MB at most; if the file is larger, TorrentBakery reduces width, frame rate and quality automatically until it fits.
